LESSON 1.2

Core Components of Computer Systems: Hardware

Take Quiz 1.2 →
Hardware & ESD Safety Warning: Always power down the workstation, unplug the PSU cable, and discharge static electricity before touching exposed motherboard circuits, CPU pins, or RAM DIMMs.

1.2.1. System Unit Components (CPU, Motherboard, Memory)

The System Unit serves as the physical engine of the Information Processing Cycle's Processing stage.

A. Central Processing Unit (CPU): The "Brain"

The CPU executes program instructions and performs all calculations and logical decisions (e.g., Intel Core i7/i9, AMD Ryzen 7/9, Apple M2/M3, Intel Xeon, AMD EPYC, Qualcomm Snapdragon SoC).

Control Unit (CU)

Coordinates and directs system operations, fetching instructions and orchestrating signal flow across hardware.

Arithmetic Logic Unit (ALU)

Performs all mathematical operations (addition, subtraction) and logical comparisons (e.g., X > Y).

CPU Registers

Ultra-fast internal memory cells located directly inside the CPU for immediate instruction operands and results.

Figure 1.2: The CPU Fetch-Execute (Instruction) Cycle.

CPU Metric Definition Practical Impact
Clock Speed (GHz) Number of instruction cycles executed per second (1 GHz = 1 billion cycles/sec). Crucial for single-threaded tasks and legacy applications.
Cores Number of independent processing units on a single chip (e.g., 4, 6, 8+ cores). Enables parallel Fetch-Execute cycles for multitasking and modern multi-threaded apps.

B. The Motherboard: The "Spine"

The main printed circuit board (PCB) physically and electronically linking the CPU, RAM, storage, and peripherals.

  • Chipset ("Traffic Cop"): Integrated circuits managing data flow between the CPU, memory, and high-speed slots.
  • Bus ("Electronic Highway"): Electronic wire pathways transferring data between components (e.g., PCIe for GPUs/NVMe SSDs; USB for external peripherals).

C. Primary Memory: RAM vs. ROM

RAM (Random Access Memory) — "Work Desk"

Volatile primary workspace for active programs and open data; contents are erased when power turns off. Types include DDR4, DDR5, LPDDR (mobile), SRAM (CPU L1/L2/L3 cache), and HBM (GPUs).

ROM (Read-Only Memory) — "Printed Manual"

Non-volatile memory that retains permanent low-level startup firmware (BIOS / UEFI) used to initialize hardware and boot the OS.

1.2.2 & 1.2.3. Input and Output Peripherals

Input Devices (Data Entry → Binary)

Convert physical actions or analog signals into binary 0s and 1s: Manual (keyboard, mouse, touchscreen), Optical (flatbed scanner, barcode reader), Acoustic (microphone ADC), and Biometric (fingerprint scanner).

Output Devices (Binary → Human Format)

Translate processed binary results into visual, audio, or physical forms: Display Screens (LCD/LED/OLED measured by resolution & Hz), Projectors (HDMI/VGA/wireless), Printers (inkjet & laser hardcopy), and Speakers/Headphones.

1.2.4. Storage Hierarchy (Primary, Secondary, Tertiary)

Tier Examples Volatility & Characteristics
1. CPU Registers & Cache Internal Registers, L1/L2/L3 SRAM Cache Fastest access speed, smallest capacity, volatile.
2. Primary Storage Dynamic RAM (DDR4/DDR5), ROM (BIOS/UEFI) Directly accessible by CPU; RAM is volatile active workspace.
3. Secondary Storage SSD (flash memory, no moving parts, fast boot), HDD (spinning magnetic platters, high capacity/low cost), USB Flash Drive, SD Card, NAS Non-volatile long-term file retention. Hybrid SSD + HDD balances speed and archival budget.
4. Tertiary / Archival Storage Magnetic Tape Drives, Automated Tape Libraries, Optical Disc Archives, Cloud Cold Storage (AWS Glacier) Massive capacity, lowest cost per GB, slowest retrieval speed for cold backups.
