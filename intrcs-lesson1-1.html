The Computing Profession and Institutional Context

1.1.1. Institutional Mandates (VMO, Core Values)

Teaching Objective: Link the technical field of computing to the University of Baguio's (UB) Vision, Mission, and Institutional Objectives to establish a professional and ethical framework from day one.

A. The Core Values Framework

COMPETENCE + INTEGRITY = SERVICE

1. COMPETENCE

Nurturing excellent technical skills — the technical mastery, analytical precision, and foundational knowledge needed to build optimized, secure computing solutions.

2. INTEGRITY

Cultivating a community with ethical values — adhering to honest professional practices, protecting data privacy, and respecting intellectual property.

3. SERVICE

Advocating sustainable programs for society and the environment — applying technical skills to create accessible, human-centric software that drives local community growth.

Practical Application: A network administrator demonstrates Integrity by refusing to view confidential employee files, and demonstrates Service by maintaining reliable internet access for remote learners.

1.1.2. Overview of Computing and the Information Processing Cycle (IPC)

Computing is any goal-oriented activity requiring, benefiting from, or creating computers. It is the art and science of information processing — encompassing the entire complex ecosystem of hardware, software, and people that solves problems using information.

The Four Stages of the Information Processing Cycle (IPC)

Figure 1.1: The Information Processing Cycle (Input → Processing → Output, supported by Storage).

  1. Input: Capturing raw, unorganized data from external environments via peripheral devices (e.g., keyboard, mouse, sensor, microphone).
  2. Processing: The Central Processing Unit (CPU) organizes, alters, and executes mathematical/logical instructions to transform raw data into meaningful information.
  3. Output: Presenting processed insights clearly to human operators or connected network destinations (e.g., monitor screen, speaker, printout).
  4. Storage: Saving data and processed results permanently or sharing digital assets for future use (e.g., HDD/SSD, flash drive, cloud storage).
Real-World Example (Submitting a Paper Online):
Input: Typing text via keyboard → Processing: Computer running word processor → Storage: Saving the file to drive/cloud → Output: Displaying the final document on screen.

1.1.3. Domains of Computing (CS, IT, CpE, IS, SE)

The computing landscape is divided into five distinct academic and professional disciplines:

  1. Computer Science (CS) — Theory and Algorithms: Rooted in mathematics; focuses on computational theory, algorithmic complexity, data structures, and software optimization. Sample Role: Algorithm Researcher, AI Scientist.
  2. Information Technology (IT) [Our Focus] — Organizational Application and Management: Focuses on selecting, deploying, integrating, securing, and maintaining computing technology within an organization. Sample Roles: Systems Administrator, Network Engineer, Web Developer, IT Support Specialist.
  3. Computer Engineering (CpE) — Hardware-Software Integration: Bridges computer science and electrical engineering to design electronic hardware and embedded software. Sample Roles: Microprocessor Designer, Embedded Systems & Robotics Engineer.
  4. Information Systems (IS) — Business and Management: Bridges technical systems and business processes, focusing on enterprise resource planning (ERP), data workflows, and analytics. Sample Roles: Business Analyst, ERP Consultant, Database Manager.
  5. Software Engineering (SE) — Systematic Software Development: Applies disciplined engineering methods across the entire software life cycle, prioritizing architecture patterns, quality assurance, and reliability. Sample Roles: Software Architect, QA Engineer.

1.1.4. The Profession: Careers, Ethics, and Equity

A. Career Tracks in Computing

  • Core IT Roles: System Administrator, Network Engineer, Database Administrator, Web Developer, IT Support Specialist.
  • Infrastructure & Emerging Tracks: Cloud Engineer, Cybersecurity Analyst, Cyber-Defense Analyst, Data Scientist.
  • Application & Theoretical Tracks: Full-Stack Developer, DevOps Engineer, Systems Architect, AI Engineer.

B. Professional Codes of Conduct (ACM & IEEE Standards)

  • Public Interest First: Systems must protect public safety, safeguard user data privacy, and minimize environmental harm.
  • Asset Integrity: Professionals must respect intellectual property rights, avoid unauthorized code duplication or piracy, and transparently report system bugs.
  • Equity and Inclusivity: Software development must actively avoid algorithmic bias and ensure user interfaces are accessible to people of all abilities.
