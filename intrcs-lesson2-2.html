LESSON 2.2

Encoding Standards — Text, Images, Audio, and Machine Code

Take Quiz 2.2 →
Data Type Distinction Warning: The text character '5' (ASCII 53 = 001101012) is stored differently from the numeric integer 5 (000001012) used in CPU math operations.

2.2.1. Encoding Multimedia and Software into Binary

An encoding standard is the "Rosetta Stone" dictionary mapping human-readable characters, colors, and sounds into agreed-upon binary sequences.

1. Digital Images (RGB Pixels)

Images consist of a grid of pixels. In 24-bit RGB color, Red, Green, and Blue each use 8 bits (0–255 intensity), totaling 3 bytes (24 bits) per pixel and 16,777,216 colors.
Pure Red: 11111111 00000000 000000002.

2. Digital Audio (ADC)

An Analog-to-Digital Converter (ADC) digitizes sound waves via Sampling (taking amplitude snapshots per second, e.g., 44.1 kHz CD rate) and Quantization (mapping each sample to discrete binary values using a Bit Depth like 16-bit).

3. Software Machine Code

High-level code (Python, Java, C++, JS) is compiled or interpreted into CPU-specific binary machine code instructions executed directly by the processor architecture (x86 vs. ARM).

2.2.2. Character Encoding: ASCII vs. Unicode

Feature ASCII (Standard & Extended) Unicode (UTF-8, UTF-16, UTF-32)
Bit Width 7-bit (128 characters: 27); Extended ASCII used 8-bit (256 codes, inconsistent across vendors). Variable length: UTF-8 uses 1 byte for ASCII and 2–4 bytes for global characters/emojis.
Character Scope English uppercase (A–Z), lowercase (a–z), digits ('0'–'9'), punctuation, and control codes. Over 140,000+ characters across all world languages (ñ, Kanji 汉, Arabic), math symbols, and emojis (🚀).
Key Decimal Codes Space = 32 (00100000), '!' = 33, '0' = 48, 'A' = 65 (01000001), 'a' = 97 (01100001). First 128 code points (0–127) are 100% backward-compatible with 7-bit ASCII.
