LESSON 3.2

Cybersecurity Threats, Defensive Layers, and Ethical Hacking

Take Quiz 3.2 →
Ethical Hacking Legal Warning: Penetration testing is strictly legal only with explicit written authorization from the system owner. Unauthorized intrusion violates Republic Act No. 10175 (Cybercrime Prevention Act of 2012).

3.2.1. Common Malware Threats

Malware (Malicious Software) is any code built to disrupt operations, steal sensitive data, or gain unauthorized system access:

1. Computer Viruses

Malicious code segments that attach to legitimate host executables and require human action (opening an infected file) to spread.

2. Network Worms

Self-replicating programs that automatically propagate across network connections by exploiting vulnerabilities without human interaction.

3. Trojan Horses

Malware disguised as useful, legitimate applications that opens hidden backdoors once installed; does not self-replicate.

4. Ransomware

Encrypts a victim's files and locks access until a ransom payment is made for the decryption key.

Social Engineering Alert — Phishing: Attackers impersonate trusted entities (banks, admins) via urgent emails or fake login pages to deceive users into revealing passwords or credit card credentials.

3.2.2 & 3.2.3. Layered Defense and Security Best Practices

Defensive Control Mechanism & Security Purpose
Network Firewalls Digital security barriers that inspect and filter incoming and outgoing traffic against predefined rules, blocking unauthorized connections.
Heuristic Antivirus Scans files for known malware signatures and monitors active processes for suspicious behavior to catch zero-day threats.
Cryptographic Encryption Scrambles readable plaintext into unreadable ciphertext using mathematical keys so intercepted data stays confidential.
Data Redundancy & Backups Maintains isolated off-site or cloud copies of critical data to guarantee recovery after ransomware or hardware failure.
Ethical Hacking (Pen Testing) Authorized security specialists simulate cyberattacks to discover and patch vulnerabilities before malicious actors exploit them.
Principle of Least Privilege Restricts every user account to the minimum access permissions required for their role, limiting blast radius if compromised.
Multi-Factor Authentication (MFA) Requires two or more independent verification factors (e.g., password + mobile authenticator code) to block stolen-password logins.
