Core Components — Software & Software Licensing

1. Which piece of system software acts as the 'grand conductor' that manages all hardware and software resources on a computer?
2. When you connect a new printer or graphics card to your PC, what type of system software translates commands between the OS and that specific hardware?
3. Which software category acts as the 'software glue' or bridge enabling separate applications and databases (via JDBC/ODBC or RabbitMQ) to communicate?
4. Adobe Acrobat Reader and Google Chrome are distributed at $0 cost to users, yet their underlying proprietary source code remains closed and controlled by the vendor. What category is this?
6. Which software licensing category has zero copyright or intellectual property restrictions because the creator explicitly relinquished all rights (e.g., SQLite)?
