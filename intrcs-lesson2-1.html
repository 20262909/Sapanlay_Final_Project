LESSON 2.1

Data Representation, Bits & Bytes, and Number System Conversion

Take Quiz 2.1 →
Base Notation Warning: Always write the base subscript (e.g., 1012 vs. 10110 vs. 10116) so binary, decimal, octal, and hexadecimal values are never misread.

2.1.1. Bits, Bytes, and Digital Storage Units

  • Bit (Binary Digit): The smallest unit of computer data, representing two reliable electronic voltage states: 0 (OFF/False) or 1 (ON/True).
  • Byte: Universally consists of exactly 8 bits (28 = 256 combinations, from 000000002 = 0 to 111111112 = 255).
  • Decimal (SI) vs. Binary (IEC) Prefixes: Hard drive manufacturers market capacity using base-10 powers (1 KB = 1,000 bytes; 1 TB = 1012 bytes), whereas operating systems and RAM use base-2 powers (1 KiB = 210 = 1,024 bytes; 1 MiB = 220 = 1,048,576 bytes; 1 GiB = 230 bytes).

2.1.2. The Four Core Number Systems

Number System Base Allowed Digits / Symbols Place Values (Right to Left) Primary Computing Use
Binary Base-2 0, 1 20 (1), 21 (2), 22 (4), 23 (8), 24 (16)... Native machine language of digital circuits
Octal Base-8 0, 1, 2, 3, 4, 5, 6, 7 80 (1), 81 (8), 82 (64), 83 (512)... Compact shorthand (1 octal digit = 3 bits; Unix file permissions)
Decimal Base-10 0–9 100 (1), 101 (10), 102 (100), 103 (1000)... Everyday human counting and arithmetic
Hexadecimal Base-16 0–9, A(10), B(11), C(12), D(13), E(14), F(15) 160 (1), 161 (16), 162 (256), 163 (4096)... 1 hex digit = 4 bits (nibble); 2 hex digits = 1 byte; HTML colors (#FF0000), MAC & memory addresses

2.1.3. Step-by-Step Conversion Methods

A. Other Bases → Decimal (Positional Notation)

Multiply each digit by its base raised to its position index (starting at 0 on the far right) and sum the products.
Example (11012): (1×8) + (1×4) + (0×2) + (1×1) = 1310.
Example (1A16): (1×16) + (10×1) = 2610.

B. Decimal → Binary (Repeated Division by 2)

Divide the decimal number repeatedly by 2, record each remainder (0 or 1), and read remainders from bottom to top (MSB to LSB).
Example (2510): 25÷2=12 r1, 12÷2=6 r0, 6÷2=3 r0, 3÷2=1 r1, 1÷2=0 r1 → 110012.

C. Binary ↔ Octal (3-Bit Grouping)

Group binary digits in sets of 3 bits from right to left (pad left with 0s).
Example: 101112 → 010 111 → 278.

D. Binary ↔ Hexadecimal (4-Bit Grouping)

Group binary digits in sets of 4 bits from right to left (pad left with 0s).
Example: 110101102 → 1101 (13=D) 0110 (6) → D616.
