Core Components — Software & Software Licensing

1.3.1 & 1.3.2. The Three Core Categories of Software

Software is the complete set of digital instructions that directs every hardware component. It is organized into three functional layers:

1. System Software ("Behind-the-Scenes Boss")

Manages and controls core hardware resources so the computer is usable. Includes the Operating System, Device Drivers, Utilities, and Firmware.

2. Application Software ("The Doing Software")

End-user programs built for specific productivity, creative, or entertainment tasks (e.g., MS Word, Google Docs, Chrome, Photoshop, Excel, video games).

3. Middleware ("The Software Glue")

Connective tissue enabling disparate apps, databases, and distributed systems to communicate (e.g., JDBC/ODBC, Apache/Nginx web servers, RabbitMQ/Kafka, JBoss).

Four Sub-Components of System Software

Component Role & Analogy Examples
Operating System (OS) "The Grand Conductor" — orchestrates hardware, memory, files, and UI. Microsoft Windows, macOS, Linux (Ubuntu), Android, iOS
Device Drivers "The Translators" — allows the OS to communicate with specific hardware peripherals. Printer Drivers, GPU Graphics Card Drivers, Webcam Drivers
Utilities "The Maintenance Crew" — optimizes, protects, and maintains files and drives. Antivirus (Avast/Norton), Disk Defragmenter, WinRAR/7-Zip, Disk Cleaners
Firmware "Embedded Instructions" — permanently stored in hardware ROM for low-level boot control. Motherboard BIOS/UEFI, Wi-Fi Router Firmware, Smart TV Firmware

1.3.3. Six Software Categories by Licensing

License Category Analogy Source Code & Legal Rights Examples
1. Proprietary "My house, my rules." Closed-source; owner holds exclusive IP rights under a restrictive EULA; users cannot modify or redistribute. Windows, Adobe Photoshop, macOS, MS Office, AutoCAD
2. Commercial "I sell my house." Developed and sold/licensed for profit (one-time or subscription) with vendor support. Windows, Adobe Creative Cloud, QuickBooks, SAP ERP
3. Open Source (OSS) "My blueprint is public." Source code is publicly available to inspect, modify, and redistribute collaboratively. Linux, Mozilla Firefox, VLC Media Player, GIMP, Apache
4. Freeware "Live free, still mine." Proprietary (closed-source) software distributed at $0 cost; modification/redistribution restricted. Adobe Acrobat Reader, Google Chrome, Skype, Avast Free
5. Shareware "Try for a month, then pay." "Try before you buy" trial basis (time-limited, nag screens, or limited features) before payment. WinRAR evaluation, 30-day antivirus trials, game demos
6. Public Domain "For everyone, forever." No copyright or IP restrictions; creator relinquished all rights; usable/modifiable for any purpose. SQLite database library, expired-copyright code
