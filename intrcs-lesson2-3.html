2.3.1. Boolean Algebra Fundamentals (AND, OR, NOT)

Boolean Algebra is a mathematical framework where variables hold only two truth values: True (1) and False (0). Physical electronic circuits called Logic Gates implement these rules inside microprocessors.

Figure 2.3: Core Boolean Logic Gates (AND, OR, NOT).

Input A Input B AND (A · B) OR (A + B) NAND (A · B)' NOR (A + B)' NOT A (A')
0000111
0101101
1001100
1111000
The Universal Gate Principle: NAND and NOR gates are classified as universal gates because any foundational Boolean function (AND, OR, NOT) can be built using exclusively NAND gates or exclusively NOR gates, simplifying microchip manufacturing.
